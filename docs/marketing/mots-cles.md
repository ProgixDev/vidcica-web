se concurrencent sur la même recherche. Priorité : **P1** = à traiter en premier (intention
d'achat forte), **P2** = ensuite, **P3** = contenu de fond.

## Règles de rédaction

1. **Un mot-clé principal par page**, placé dans le titre, le H1, l'introduction et l'URL.
2. **Un seul H1 par page.**
3. Titre de page : 50-60 caractères. Description : 140-160 caractères, avec un appel à l'action.
4. Chaque page renvoie vers 2 à 3 autres pages du site (maillage interne).
5. Ne jamais créer deux pages sur le même mot-clé : elles se concurrenceraient.
